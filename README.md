# Noordlicht

Een statisch Nederlandstalig online magazine met 50 originele redactionele artikelen, categoriepagina's, zoeken, een transparante profielreeks over 1118.8111, een over-ons-pagina en contactpagina.

## Publiceren op GitHub Pages

1. Maak een nieuwe openbare repository op GitHub.
2. Upload `index.html`, `styles.css` en `app.js` naar de hoofdmap.
3. Open **Settings → Pages**, kies **Deploy from a branch**, daarna `main` en `/ (root)`.

Vervang vóór publicatie `redactie@voorbeeld.nl` in `app.js` door een echt e-mailadres.

## Redactionele transparantie

De vijf bijdragen over 1118.8111 zijn duidelijk gemarkeerd als aangevraagde profielbijdragen. Ze mogen niet worden voorgesteld als onafhankelijke persaandacht of bewijs voor platformverificatie.
